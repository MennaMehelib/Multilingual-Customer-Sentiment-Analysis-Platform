# Exploratory Notebooks

This directory is designated for exploratory analysis and visualization notebooks.

### Guidelines for Team Members:
- Always consume standardized datasets from `../data/processed/splits/` (`train.csv`, `validation.csv`, `test.csv`).
- Import preprocessing functions from `src.preprocessing` rather than writing ad-hoc cleaning in notebooks.
- Keep notebooks reproducible and committed with output cells cleared if they contain large binaries.
